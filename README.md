# Pong Arcade

A simple browser Pong game built with HTML, CSS, and JavaScript.

## Features
- Player controls the left paddle with mouse or Up/Down arrow keys
- Right paddle is a computer-controlled AI opponent
- Bouncing ball with wall and paddle collision detection
- Scoreboard and win condition
- Pause/resume
- Difficulty settings: Easy, Medium, Hard
- Sound toggle with synthesized Web Audio effects

## Run locally
1. Clone the repository.
2. Open `index.html` in a browser.

## Controls
- Mouse: move over the game area to control the left paddle
- Arrow keys: Up/Down to move the left paddle
- Space: pause/resume

## Project files
- `index.html`
- `style.css`
- `script.js`
- `index.bundle.html` (single-file bundled version)
